# GAFE v0.1.0

The first public release of GAFE, a Game Boy Advance focused frontend for the ANBERNIC RGSP running StockOS v1.0.1.

## Highlights

- Animated GBA cartridge carousel with fitted RetroArch Boxart.
- Japanese game-title support.
- Wi-Fi scanning, password entry, and connection management.
- Persistent hardware volume control during games.
- SELECT + Volume brightness shortcuts without unintended volume changes.
- System menu actions for StockOS restoration, restart, and shutdown.
- Persistent GAFE-specific RetroArch, shader, and mGBA settings.
- Safe backup and restoration of the original StockOS launcher and settings.
- Packaged XMB configuration, GBA shader preset, mGBA options, and wallpaper.
- English and Japanese documentation.

## Installation

1. Extract `GAFE-v0.1.0.zip`.
2. Copy `GAFE-ON.sh`, `GAFE-OFF.sh`, and `GAFE` into the SD card's `Roms/PORTS` directory.
3. On the device, open `RA game` -> `PORTS` -> `GAFE-ON`.
4. The device reboots automatically into GAFE.

See the [English README](https://github.com/game-de-it/GAFE/blob/main/README.md) or [Japanese README](https://github.com/game-de-it/GAFE/blob/main/README.ja.md) for controls, Boxart setup, persistence behavior, and StockOS recovery.

## Compatibility

This release targets the ANBERNIC RGSP StockOS v1.0.1 environment. RetroArch, mGBA, ROMs, and BIOS files are not included.

## Wallpaper

The included wallpaper is based on **Chill Mario 2023 ver.** by **Pixel Jeff (Jeff Lin)**. See [THIRD_PARTY_NOTICES.md](https://github.com/game-de-it/GAFE/blob/main/THIRD_PARTY_NOTICES.md).

- 音量を変えずに使えるSELECT＋音量ボタンの画面輝度操作。

## 導入方法

1. `GAFE-v0.1.0.zip`を展開します。
2. `GAFE-ON.sh`、`GAFE-OFF.sh`、`GAFE`フォルダをSDカードの`Roms/PORTS`へコピーします。
3. 実機で`RA game` -> `PORTS` -> `GAFE-ON`を実行します。
4. 自動再起動後にGAFEが表示されます。

操作方法、Boxart取得、設定の永続化、StockOS復旧については[日本語README](https://github.com/game-de-it/GAFE/blob/main/README.ja.md)を参照してください。
