# GAFE v0.1.1

GAFE v0.1.1 fixes shader persistence when returning from StockOS to GAFE.

## Fixed

- Reapplies the saved global shader preset and GBA mGBA options at GAFE session startup, after the StockOS runtime finishes initializing RetroArch directories.
- Prevents the GBA shader from being lost after `Restore StockOS` followed by `GAFE-ON`.

## Installation

1. Extract `GAFE-v0.1.1.zip`.
2. Replace `GAFE-ON.sh`, `GAFE-OFF.sh`, and the `GAFE` folder in the SD card's `Roms/PORTS` directory.
3. On the device, open `RA game` -> `PORTS` -> `GAFE-ON`.

This release targets the ANBERNIC RGSP StockOS v1.0.1 environment.

GAFE v0.1.1では、StockOSからGAFEへ戻した際にシェーダー設定が失われる問題を修正しました。

## 修正内容

- StockOSランタイムによるRetroArchディレクトリの初期化後、GAFEセッション開始時に保存済みのグローバルシェーダーとGBA用mGBA設定を再適用します。
- `Restore StockOS`の後に`GAFE-ON`を実行した場合でも、GBAシェーダーが維持されます。

## 導入方法

1. `GAFE-v0.1.1.zip`を展開します。
2. SDカードの`Roms/PORTS`にある`GAFE-ON.sh`、`GAFE-OFF.sh`、`GAFE`フォルダを置き換えます。
3. 実機で`RA game` -> `PORTS` -> `GAFE-ON`を実行します。

対象環境はANBERNIC RGSP StockOS v1.0.1です。
