# GAFE v0.1.2

GAFE v0.1.2 improves battery efficiency by selecting the dynamic `ondemand` CPU governor when GAFE starts.

## Added

- Sets every CPU frequency policy that supports `ondemand` to that governor at GAFE session startup.
- Logs a warning and continues startup if a device does not expose a compatible CPU frequency policy.
- Documents the update procedure for existing GAFE installations.

## Updating from v0.1.1

1. In GAFE, press SELECT and use `Restore StockOS`.
2. Extract `GAFE-v0.1.2.zip`.
3. Replace `GAFE-ON.sh`, `GAFE-OFF.sh`, and the `GAFE` folder in the SD card's `Roms/PORTS` directory.
4. On the device, open `RA game` -> `PORTS` -> `GAFE-ON`.

Keep `/mnt/mmc/GAFE_HOME` in place. Existing GAFE settings and the original StockOS backup are reused.

This release targets the ANBERNIC RGSP StockOS v1.0.1 environment.

## 追加内容

- `ondemand`に対応するすべてのCPU周波数ポリシーへ、GAFEセッション開始時に設定を適用します。
- 対応するCPU周波数ポリシーがない場合は警告を記録し、起動処理は継続します。
- 既存GAFE環境の更新手順をドキュメントへ追加しました。

## v0.1.1からの更新

1. GAFEでSELECTを押し、`Restore StockOS`を実行します。
2. `GAFE-v0.1.2.zip`を展開します。
3. SDカードの`Roms/PORTS`にある`GAFE-ON.sh`、`GAFE-OFF.sh`、`GAFE`フォルダを置き換えます。
4. 実機で`RA game` -> `PORTS` -> `GAFE-ON`を実行します。

`/mnt/mmc/GAFE_HOME`は削除しないでください。既存のGAFE設定と元のStockOSバックアップが引き継がれます。

対象環境はANBERNIC RGSP StockOS v1.0.1です。
